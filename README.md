# James's Coffee Store Website

這是一個使用 React + Vite + Tailwind CSS 打造的精美咖啡店網頁。

## 技術棧
- **React 19**
- **Vite 6**
- **Tailwind CSS 4**
- **Lucide React** (圖標)
- **Framer Motion** (動畫)

## 本地開發

1. 安裝依賴：
   ```bash
   npm install
   ```

2. 啟動開發伺服器：
   ```bash
   npm run dev
   ```

## 部署
本專案已配置 GitHub Actions，推送至 `main` 分支時會自動部署到 GitHub Pages。
